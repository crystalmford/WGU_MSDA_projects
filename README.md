# Churn Model Experiment Tracking with MLflow

This project demonstrates a modular machine learning workflow for customer churn prediction, with integrated experiment tracking using MLflow. It was originally developed as part of the D602 Task 2 assignment for WGU's MSDA program.

## Project Goals

- Import and clean raw customer data
- Filter data based on relevant criteria
- Train a Ridge regression model using polynomial features
- Track model parameters and performance using MLflow
- Structure all components into a reproducible pipeline using an MLProject file

---

## Tools & Libraries

- Python
- MLflow – Experiment tracking
- Scikit-learn – Model training
- Pandas / NumPy – Data manipulation
- DVC (optional) – Data versioning
- Git – Version control
