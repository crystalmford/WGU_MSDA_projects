# Data Science Portfolio – Crystal Ford

This repository contains selected data science projects completed as part of my Master of Science in Data Analytics at Western Governors University (WGU), with a specialization in Data Science. Each project is organized in its own Git branch to maintain a clear and professional structure.

---

## About Me

I am a mission-driven data scientist in training with a background in education and nonprofit leadership. I’m passionate about using data to support underserved communities and drive meaningful insights. My current focus areas include predictive modeling, customer segmentation, and time series forecasting.

---

## Projects

Each of the following branches contains a self-contained project with cleaned code, a professional README, and (when applicable) a final report.

### Landmark Image Classification with CNN
**Branch:** [`cnn-project`](https://github.com/crystalmford/WGU_MSDA_projects/tree/cnn-project)  
**Description:** Built a convolutional neural network from scratch and improved it with transfer learning (ResNet18) to classify images of 50 landmarks. Final model exported for real-time prediction.

### Customer Churn Prediction Model
**Branch:** [`churn-prediction`](https://github.com/crystalmford/WGU_MSDA_projects/tree/churn-prediction)  
**Description:** A Random Forest classifier built to identify customers likely to churn.

### Customer Segmentation with K-Means
**Branch:** [`customer-segmentation-kmeans`](https://github.com/crystalmford/WGU_MSDA_projects/tree/customer-segmentation-kmeans)  
**Description:** An unsupervised clustering model used to group customers based on behavioral attributes.

### Customer Revenue Forecasting with ARIMA
**Branch:** [`customer-revenue-forecasting`](https://github.com/crystalmford/WGU_MSDA_projects/tree/customer-revenue-forecasting)  
**Description:** A time series forecasting model using ARIMA to project future customer revenue.
