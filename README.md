# Data Science Portfolio – Crystal Ford

This repository contains selected data science and data analysis projects completed as part of my Master of Science in Data Analytics at Western Governors University (WGU), with a specialization in Data Science. Each project is organized in its own Git branch to maintain a clear and professional structure.

## About Me

I am a mission-driven data scientist in training with a background in education and nonprofit leadership. I’m passionate about using data to support underserved communities and drive meaningful insights. My current focus areas include predictive modeling, machine learning deployment, and customer segmentation.

## Data Science Projects

| Project Name                          | Branch                          | Description                                                                 |
|--------------------------------------|----------------------------------|-----------------------------------------------------------------------------|
| **Landmark Image Classification**    | `cnn-project`                   | Built a CNN and applied transfer learning to classify 50 landmark images.   |
| **Customer Churn ML Model**          | `customer-churn-ml-model`       | End-to-end churn prediction pipeline with feature engineering and modeling. |
| **Flight Delay Prediction API**      | `flight-delay-prediction-api`   | Trained a flight delay model and deployed it using FastAPI.                 |

| **Model Experiment Tracking**        | `model-experiment-tracking`     | Tracked ML model versions and results using MLflow.                         |
| **Predictive Modeling Projects**     | `predictive-modeling-projects`  | A collection of supervised ML models for various business scenarios.        |
